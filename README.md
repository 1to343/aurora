# ERP Микрочипы — MVP (Этап 1)

## Быстрый запуск

### 1. Установить зависимости

```powershell
cd C:\Users\MrRent.ru\Desktop\erp-microchip
pip install -r requirements.txt
```

### 2. Заполнить базу тестовыми данными

```powershell
python seed.py
```

### 3. Запустить сервер

```powershell
uvicorn app.main:app --reload
```

Приложение откроется по адресу: **http://127.0.0.1:8000**

## Что реализовано (Этап 1 по ТЗ)

- **Авторизация** — JWT в cookie, 9 ролей RBAC, аудит-лог всех действий
- **Склад (WMS)** — приёмка материалов, остатки по ячейкам/партиям, выдача FIFO/FEFO, перемещения, точка заказа, опасные вещества
- **Производство** — Work Orders, маршрутные карты (литография → травление → диффузия → металлизация → корпусирование), партии (lot/wafer), регистрация операций, статусы HOLD/PASS/REJECT/DONE
- **Аналитика** — дашборд с WIP, уровнем дефектности, статусами WO и партий
- **Аудит** — полная история действий с IP и временем
